# Student Retention & Persistence Dashboard

## Overview
This project analyzes undergraduate student retention and persistence trends using a mock institutional dataset. It demonstrates SQL extraction, Excel cleaning, SPSS descriptive statistics, and a Power BI/Tableau dashboard.

## Tools Used
- SQL
- Excel
- SPSS
- Power BI or Tableau

## Files
- /data/retention_mock_data.xlsx
- /sql/retention_queries.sql
- /spss/retention_analysis.sav
- /spss/retention_output.spv
- /dashboard/PowerBI.pbix or Tableau.twbx

## Insights
- Retention increased from 78% → 82% over 3 years  
- First‑gen students improved by 5 points  
- STEM programs show highest persistence  
- GPA < 2.5 strongly predicts stop‑out
